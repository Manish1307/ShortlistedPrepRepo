Before you install

  • Windows 10 (version 2004 or later) or Windows 11, 64-bit
  • 8 GB of memory and a recent multi-core processor recommended
  • About 500 MB of free disk space
  • An internet connection for the AI answers
  • A Google Gemini or Anthropic Claude API key (how to get one)

Install in four steps

Run the installer

Open the downloaded file and follow the prompts. If Windows shows a SmartScreen warning, check that the publisher name is correct before choosing Run.

Let it finish setting up

On first start, the app downloads the offline speech model once.

Add your AI key

Open the ⚙ settings in the assistant window and paste your key.

Do a test call

Join a test meeting with a colleague, share your screen, and confirm the assistant window is not visible to them.
